# Gazetteer

`states.csv` lists the 58 UN Member States of 1948 (the membership during the UDHR drafting), with the name variants the records use. The Covenant period (1949–66) adds the later members; extend the list in Phase 3.

Non-state participants (specialised agencies, NGOs, the Secretariat, CHR sub-bodies) aren't listed here. They are taken from each meeting's attendance list (`pipeline/entities.py`), which is also the source for delegates' names.
